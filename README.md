# HartMath support and privacy

Public information pages for HartMath. The application source code and learner data are not part of this repository.

- [Support](https://nahart86.github.io/HartMath-Support/support/)
- [Privacy policy](https://nahart86.github.io/HartMath-Support/privacy/)

Parents and guardians may use this repository’s public issues for non-sensitive support questions. Do not include children’s names, learning history, PINs, Apple Account details or payment information.
