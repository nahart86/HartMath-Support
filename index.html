Local practice

Practice, learner profiles, story problems, hints, worked explanations, adaptive practice and recommendations are free. Choose any combination of Find the answer, Find the missing number and Story problems in onboarding or Settings. Profiles, practice history and saved rounds stay on this device while iCloud learning-data sync is disabled. Restoring Pro does not move that data to another device.

Optional BrightTurn sharing

Parents with verified Pro access can enable eligible future-round summaries for their own compatible BrightTurn server. This requires parent confirmation on each device; it does not enable iCloud sync or upload previous history. A compatible family server must be set up separately; live household reward delivery has not been qualified. Read the privacy policy for the connection’s data handling.
