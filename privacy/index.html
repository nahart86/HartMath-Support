Privacy policy

Last updated October 11, 2026 · TestFlight 1.2 (4) and upcoming 1.2 (6)

HartMath is a math practice app for iPhone, iPad and Apple TV. This policy covers the current TestFlight build 1.2 (4) and separately describes the planned data handling of upcoming build 1.2 (6).

Current TestFlight build: 1.2 (4). Upcoming build: 1.2 (6). Build 6 is still being tested and is not yet available in TestFlight. Features marked “Upcoming build 6” below are not available in build 4. Check the version and build shown in TestFlight before following those instructions.

Learner profiles and practice

HartMath saves learner names or nicknames, chosen avatars, practice preferences, optional profile PIN credentials, scores, rewards, practice dates and time, and question attempts on the device. Upcoming build 6 will also save unfinished rounds on the device. You can use a nickname; a learner profile does not require an email address or a separate online account.

Saved practice history supports progress reports; Pro reports are calculated from that history. Upcoming build 6 will also use saved state to continue unfinished rounds. Guest rounds are not saved as learner history.

Profile PINs and parent controls

Current versions store a salted, derived PIN verifier rather than the entered PIN. Older local PIN records are upgraded when they are loaded. A profile PIN is a convenience lock for selecting a learner; it is not an online password or a guarantee that all device data is encrypted by HartMath.

On supported iPhone and iPad devices, parent controls can ask the system to authenticate the device owner. HartMath receives the authentication result, not biometric templates. A reading challenge is used when device authentication is unavailable and on Apple TV.

Device storage and iCloud

iCloud syncing is not enabled in build 4 or the current build 6 candidate. These builds do not upload learner profiles, practice history or unfinished rounds to iCloud or a HartMath learning-data server. Selecting the same Apple Account on another device does not transfer learner data between these builds.

Device backups are separate from HartMath syncing and follow your Apple device and backup settings. During storage recovery, HartMath may preserve damaged or interrupted local data on the device so that it is not silently replaced. Apple TV may remove local saved files to free space; local storage there is not a permanent backup.

If a later version enables iCloud learning-data syncing, this policy will describe the enabled behavior before that version is released.

Upcoming build 6: optional BrightTurn connection

BrightTurn sharing is not present in build 4. The following paragraphs describe how the optional connection will handle data in build 6 once that build is available. A parent with verified HartMath Pro access will be able to connect a saved learner on this device to a compatible family-operated BrightTurn server. This is off until a parent completes the parent check, enters that server’s HTTPS address and private pairing code, checks the learner label and reward rules returned by BrightTurn, and explicitly enables sharing. HartMath does not create a BrightTurn account or select a server for you.

Sharing applies to eligible rounds started after enabling on this device. An unfinished round can also qualify when the learner explicitly continues it here, but only if sharing was already enabled on this device before that round originally started. Importing history or opening the app does not authorize an imported round for sharing. Each result contains a schema version, session identifier, completion time, number of distinct cards with submitted answers, number of those cards answered correctly, and active practice duration. HartMath does not send the learner’s name or local profile identifier, profile PIN, individual questions or answers, Apple Account details, or purchase records to BrightTurn. Pairing does not upload completed history or rounds that began before enabling on this device. Guest practice cannot connect.

The pairing code is sent to the server you enter and is not retained as a saved code in HartMath. The resulting scoped connection credential, server address, returned learner label and rules, consent, pending results and receipt status are kept in a device-only Keychain item. The connection and pending queue stay on this device and do not sync through iCloud. Each device needs its own parent-confirmed connection; this optional sharing does not enable learning-data sync. Pending results can remain locally while offline or while Pro is not verified; sending is attempted only while the app is open, online and Pro access is verified, and the connection and parent rule still permit it. Delivery is not guaranteed; the server may reject an expired result or connection.

BrightTurn sharing sends directly to the family server; it does not use a developer-operated central collection service. That server can associate the result with the BrightTurn learner selected during pairing and receives the ordinary connection information needed to handle an HTTPS request. The family server operator controls its records, access, retention and deletion. Ask that operator about information already received.

Disconnect remains available without Pro. It removes the connection and unsent results for that learner from this device and attempts to revoke the server credential. If the server is unreachable, revoke the connection from the BrightTurn parent dashboard too. Successful server revocation cancels pending rewards. Time already granted and previously accepted server records remain. HartMath history remains on the device. A reward depends on the parent’s server rules, limits and successful delivery; HartMath does not independently verify learning activity or guarantee a reward.

Apple subscriptions

Apple processes purchases, billing and renewals. HartMath uses Apple's StoreKit service and verified transaction information to determine Pro access and restore an existing subscription. HartMath does not receive payment card details.

Subscription access and learner data are separate. Restoring Pro access does not transfer locally saved learner profiles or history. Deleting a learner or removing the app does not cancel a subscription. Manage or cancel through Apple's subscription controls. Apple's handling of App Store information is described in App Store & Privacy.

Voices, sounds and tracking

Question narration uses Apple's on-device speech synthesis with installed voices. HartMath does not record microphone audio or send question text to a separate narration provider. Sound effects are bundled with the app.

HartMath does not include advertising, third-party tracking analytics or advertising identifiers. Its educational reports describe practice within the app; they are not advertising analytics.

Your choices

You can change a learner's name, avatar and practice settings in Profiles. Delete a learner there to remove that learner from the current profiles and saved practice history on the device. Local recovery copies and operating-system backups are separate from the current learner list. Manage data on each device separately while syncing is disabled. For an optional BrightTurn connection, use Disconnect in HartMath and the family server’s controls for any records already received.

Parents and guardians can choose nicknames and control access to learner profiles. There is no need to send a child's real name or practice history when asking for general support.

Beta feedback and external pages

If you use TestFlight, Apple can share testing information and feedback with the developer, including crashes and usage information. See Apple's TestFlight information. This is separate from HartMath's educational progress reports.

These static information pages contain no analytics scripts or advertising. GitHub hosts this website and the public support tracker and handles service information under GitHub's privacy statement. Opening Apple or other links also contacts those services.

If an adult chooses to post a support issue, the developer and the public can read the GitHub username, message and any attachments. Use the tracker only for non-sensitive app questions. Do not post a child's name, profile PIN, learning history, Apple Account details or payment information.

Questions and updates

Parents and guardians can contact the developer through the support page for app or privacy questions. The linked issue tracker is public; ask a general question without including personal information. HartMath does not offer a private support form on this website.

Changes to this policy will be published with an updated date.
