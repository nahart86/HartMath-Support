For parents and teachers

Contact support

Ask a question or report a problem in the HartMath public support tracker. A GitHub account is needed to post. Children should ask a parent or guardian to contact support.

Open public support tracker

Posts and attachments are public. Do not include children's names, practice history, profile PINs, Apple Account passwords or payment details. Crop personal information from screenshots before posting. This is not a private support form.

What helps us investigate

  • Device model, system version and app version/build.
  • The steps you took, what you expected, and what happened.
  • The exact error message or a screenshot with personal details removed.

Beta testers can also use Send Beta Feedback in TestFlight. See Apple's TestFlight feedback instructions.

Common questions

Start with the right learner

In build 4, use Profiles to choose or edit a learner and manage an optional PIN, then return to Play. Guest is available for a quick round without saving learner history.

Upcoming build 6: A welcome flow and full-screen learner selector will make choosing a profile easier. “Ask who's practicing on launch” in Settings will control whether the selector appears when the app opens. Home will include a profile button for switching learners.

Make practice yours

In build 4, Settings lets you choose operations, number range and cards per round. Number keypad and Multiple choice work with ordinary and missing-number equations.

Upcoming build 6: Story problems, optional adaptive practice, hints and recommended practice will also be free. Adaptive practice will start off. Practice settings will apply to the next new round; a saved round will keep the settings with which it started.

Use Playful or Standard answer sounds and preview each outcome. For narration, turn on Read questions aloud, then choose Automatic or an installed Apple voice and a reading speed. The voices available depend on what is installed on the device.

Upcoming build 6: continue a saved round

A named learner will be able to save an unfinished round and continue from Home on the same device. Choose that learner first, including its PIN if one is set. Guest practice will not create a saved learner round. Build 4 does not have this saved-round continuation control.

Cross-device learning sync is not enabled in build 4 or the current build 6 candidate. Profiles and history remain on each device, as will build 6’s saved rounds. Restoring a Pro subscription on another device does not copy that learning data.

Pro access and subscriptions

Practice, local profiles and immediate round results are free. HartMath Pro is for saved reporting and analytics. Where subscription plans are available, the app displays the price and billing period supplied by Apple; build 4 may show that new subscriptions are not available yet.

Upcoming build 6: Story problems, adaptive practice, hints and recommendations will remain free. Verified Pro will also allow optional BrightTurn pairing and sending when a compatible family server is configured.

If you already have Pro, open the Pro area from Reports (Progress on Apple TV) or Settings in build 4, or from Progress or Settings in build 6, complete the parent check, and choose Restore Purchases. Use the Apple Account that holds the subscription and allow time for Apple to verify it. If verification fails or no plans are available, keep the exact message for your support request.

You can manage or cancel a subscription through Apple's subscription controls. Deleting a profile or uninstalling the app does not cancel billing. Apple's standard terms of use apply to the app.

Upcoming build 6: connect optional BrightTurn rewards

The instructions in this section are for build 6 once it is available; build 4 has no BrightTurn control. The connection will require a saved HartMath learner, verified Pro access, and a compatible family-operated BrightTurn server. Free practice works without a connection. A parent sets the learner, protected reward target, minimum answered questions, reward time, daily limit and time zone in BrightTurn.

  1. Open the BrightTurn parent dashboard and create a private pairing code for the intended learner.
  2. In HartMath, choose that saved learner, open Settings → BrightTurn, and complete the parent check.
  3. Enter the full HTTPS server address without a page path, password or query, then enter the 24-character code. You can paste its grouped form with hyphens.
  4. Choose Check pairing code. Read the learner label, server and reward rules, then choose Enable sending future rounds only if they are correct. Cancel pairing if they are not.

Eligible rounds started after enabling on this device can be shared when finished. An unfinished round explicitly continued here can also qualify if sharing was already enabled on this device before that round originally started. Importing history alone does not share it, and rounds that began before enabling remain excluded. Learning-data sync is disabled in the current build 6 candidate; connecting BrightTurn does not move saved rounds between devices. The summary contains a session identifier, completion time, submitted-answer and correct-answer counts, and active practice duration. Showing an answer without submitting one does not count toward the answered-question target, and repeated guesses on the same card do not add extra answered cards.

The connection and waiting queue belong to this device and are not transferred by iCloud. Keep this app open and connected to attempt sending queued rounds; the connection and parent rule must still be valid. The status, Waiting to send count and receipt show progress; Try sending now retries when Pro is verified. Expired or unverified Pro pauses sending without stopping local practice. A received result is not a promise that time has been granted: the server applies the parent’s rules and daily limits. Offline results count against the day they are accepted, in the rule’s time zone. Results older than the server’s seven-day acceptance window cannot be delivered. HartMath does not independently verify learning activity.

If the connection storage cannot be opened, use Retry connection storage. If the server rejects an expired or revoked connection, disconnect and create a new pairing code. Do not post server credentials, pairing codes or a child’s label in public support.

To stop sharing, choose Disconnect and confirm. This remains available without Pro and removes unsent queued results from this device. It does not undo rewards already accepted by BrightTurn or remove server records. If the app could not reach the server to revoke the connection, revoke it in the BrightTurn dashboard too. This per-learner, per-device connection is separate from iCloud syncing.

Navigation and readability

Build 4 uses Play, Profiles, Reports (Progress on Apple TV) and Settings. On Apple TV, these are at the top of the screen. Use the remote to move focus and Back or Done to leave a screen.

Upcoming build 6: The main destinations will be Home, Profiles, Progress and Settings. iPhone will use tabs; iPad will provide a left sidebar when space allows, adapting for smaller windows and larger text. Apple TV will have a left-side menu.

On Apple TV, Reveal answer asks for confirmation. Keep trying is selected first so you can cancel without revealing the answer. The app also adapts to supported larger text, reduced-motion and reduced-transparency settings.

Saved-data help

If a storage-recovery message appears, keep the exact wording and use the choices shown in the app. Do not delete the app as a first troubleshooting step when you need to preserve local practice. A learner deletion is separate from subscription cancellation. Apple TV may remove local files to free space, so a copy stored only there is not a permanent backup.
