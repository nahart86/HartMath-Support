A little help with practice

Find your learner, choose how to answer, and get help for your app version.

Current TestFlight build: 1.2 (7). These instructions describe build 7. Check the version and build shown in TestFlight; older builds may have different controls. Build 7 adds mixed problem types and starts narration off for fresh settings while preserving an explicitly saved on/off choice.

For parents and teachers

Contact support

Ask a question or report a problem in the HartMath public support tracker. A GitHub account is needed to post. Children should ask a parent or guardian to contact support.

Open public support tracker

Posts and attachments are public. Do not include children's names, practice history, profile PINs, Apple Account passwords or payment details. Crop personal information from screenshots before posting. This is not a private support form.

What helps us investigate

  • Device model, system version and app version/build.
  • The steps you took, what you expected, and what happened.
  • The exact error message or a screenshot with personal details removed.

Common questions

Start with the right learner

Use Home’s learner button or Profiles to choose a learner. Profiles also lets you edit a learner and manage an optional PIN. Guest is available for a quick round without saving learner history.

The welcome flow helps create a learner and choose a starting level. “Ask who's practicing on launch” in Settings controls whether the learner selector appears when the app opens.

Make practice yours

Settings lets you choose operations, number range, cards per round and how to answer. In build 7, choose any combination of Find the answer, Find the missing number and Story problems in onboarding or Settings. Selected types have a checkmark; at least one must stay selected. In Settings, choose Done to close the selection sheet. New rounds mix only the selected types. Number keypad and Multiple choice work with each type.

Story problems, hints, worked explanations, adaptive practice and recommended practice are free. Adaptive practice starts off and can be enabled in Settings. Practice settings apply to the next new round; a saved round keeps its questions, answer choices and hint progress. Retry keeps the original questions but starts fresh answer choices and hints.

Use Playful or Standard answer sounds and preview each outcome. Narration starts off for fresh settings in build 7; an explicitly saved on/off choice is preserved. Turn on Read questions aloud, then choose Automatic or an available Apple voice and a reading speed. A saved voice keeps its name when available. If it is unavailable, Settings identifies that saved selection and narration uses an available fallback without discarding your choice. Voice availability depends on the device.

Continue a saved round

A named learner can save an unfinished round and choose Continue on Home on the same device. Choose that learner first, including its PIN if one is set. Guest practice does not create a saved learner round.

iCloud learning-data sync is disabled. Profiles, history and saved rounds remain on each device. Restoring a Pro subscription on another device does not copy that learning data.

Pro access and subscriptions

Practice, local profiles and immediate round results are free. HartMath Pro adds saved reporting and analytics. Where subscription plans are available, the app displays the price and billing period supplied by Apple. If plans are unavailable, local practice remains free.

Verified Pro also allows optional BrightTurn pairing and sending when a compatible family server is configured. Real Apple sandbox purchase, cancellation and Restore testing has not yet been qualified for this beta.

If you already have Pro, open the Pro area from Progress or Settings, complete the parent check, and choose Restore Purchases. Use the Apple Account that holds the subscription and allow time for Apple to verify it. If verification fails or no plans are available, keep the exact message for your support request.

You can manage or cancel a subscription through Apple's subscription controls. Deleting a profile or uninstalling the app does not cancel billing. Apple's standard terms of use apply to the app.

Connect optional BrightTurn rewards

The connection requires a saved HartMath learner, verified Pro access, and a compatible family-operated BrightTurn server. Free practice works without a connection. The companion service must be set up separately and has not been deployed or qualified for live household rewards. A parent sets the learner, protected reward target, minimum answered questions, reward time, daily limit and time zone in BrightTurn.

  1. Open the BrightTurn parent dashboard and create a private pairing code for the intended learner.
  2. In HartMath, choose that saved learner, open Settings → BrightTurn, and complete the parent check.
  3. Enter the full HTTPS server address without a page path, password or query, then enter the 24-character code. You can paste its grouped form with hyphens.
  4. Choose Check pairing code. Read the learner label, server and reward rules, then choose Enable sending future rounds only if they are correct. Cancel pairing if they are not.

Typing on Apple TV: A nearby iPhone or iPad can help enter the server address and pairing code. Use the same Apple Account as the Apple TV, turn on Bluetooth and Wi-Fi, then tap the keyboard notification on the iPhone or iPad when entering text on the TV. Follow Apple’s keyboard instructions for the requirements and steps.

Eligible rounds started after enabling on this device can be shared when finished. An unfinished round explicitly continued here can also qualify if sharing was already enabled on this device before that round originally started. Importing history alone does not share it, and rounds that began before enabling remain excluded. Learning-data sync is disabled; connecting BrightTurn does not move saved rounds between devices. The summary contains a schema version, session identifier, completion time, submitted-answer and correct-answer counts, and active practice duration. Showing an answer without submitting one does not count toward the answered-question target, and repeated guesses on the same card do not add extra answered cards.

The connection and waiting queue belong to this device and are not transferred by iCloud. Keep this app open and connected to attempt sending queued rounds; the connection and parent rule must still be valid. The status, Waiting to send count and receipt show progress; Try sending now retries when Pro is verified. Expired or unverified Pro pauses sending without stopping local practice. A received result is not a promise that time has been granted: the server applies the parent’s rules and daily limits. Offline results count against the day they are accepted, in the rule’s time zone. Results older than the server’s seven-day acceptance window cannot be delivered. HartMath does not independently verify learning activity.

If the connection storage cannot be opened, use Retry connection storage. If the server rejects an expired or revoked connection, disconnect and create a new pairing code. Do not post server credentials, pairing codes or a child’s label in public support.

To stop sharing, choose Disconnect and confirm. This remains available without Pro and removes unsent queued results from this device. Successful server revocation cancels pending rewards. Time already granted and previously accepted server records remain. If the app could not reach the server to revoke the connection, revoke it in the BrightTurn dashboard too. This per-learner, per-device connection is separate from iCloud syncing.

Navigation and readability

The main destinations are Home, Profiles, Progress and Settings. iPhone uses tabs; iPad provides a left sidebar when space allows, adapting for smaller windows and larger text. Apple TV has a left-side menu.

On Apple TV, use the remote to move focus and Back or Done to leave a screen. Choose Customize on Home or move right from Settings in the sidebar to enter its controls.

On Apple TV, Reveal answer asks for confirmation. Keep trying is selected first so you can cancel without revealing the answer. The app also adapts to supported larger text, reduced-motion and reduced-transparency settings.

Saved-data help

If a storage-recovery message appears, keep the exact wording and use the choices shown in the app. Do not delete the app as a first troubleshooting step when you need to preserve local practice. A learner deletion is separate from subscription cancellation. Apple TV may remove local files to free space, so a copy stored only there is not a permanent backup.
